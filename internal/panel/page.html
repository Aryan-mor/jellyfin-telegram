Bots

A bot is an account that reads the videos. The token is its password. This program never shows the full token again.

Connected bots

The bots download at the same time, so more bots make playback faster. A saved bot connects the next time the program starts.

Add a bot

How to create a bot
  1. Open @BotFather in Telegram.
  2. Send /newbot.
  3. Choose a display name, then a username that ends in bot.
  4. BotFather replies with a token. Paste that token below. Do not post it in the channel.
  5. Open the private channel, tap its name, then Administrators, then Add Administrator, and choose the bot.
  6. Leave “Post messages” on. The program uses that permission to store extracted subtitles back in the channel. A bot that is not an admin cannot read the videos.
  7. Repeat for each extra bot.

Telegram API

The API ID and API hash are required. They are not the bot token.

Where do I get these?

Telegram does not offer a public ID you can download or copy from someone else. Each person creates a pair, free, with their own phone number. This program speaks Telegram’s own protocol, and that protocol refuses a connection without this pair.

  1. Open my.telegram.org and sign in with the phone number of your Telegram account.
  2. Open API development tools.
  3. Create an application if you do not have one. The name can be jellyfin-telegram. The platform can be Desktop. The description can be short.
  4. Copy the numeric App api_id and the App api_hash into the fields below.
  5. The hash is a secret, like a password. Later, leave the hash field empty to keep the one already saved.

Channel

Main receives films and series. Home videos is personal footage only. A mirror receives the parts you choose.

Main

The private Telegram channel that holds your videos. Everything is sent here.

How to set up the channel
  1. In Telegram, create a private channel. A public channel is not used.
  2. Post the videos there. A useful file name looks like Title.Year.mkv. Or put Title (Year) on the first line of the caption, so Jellyfin does not guess the wrong film.
  3. Open any message in that channel, choose Copy Link, and paste it below. It looks like https://t.me/c/1234567890/5.
  4. Or give the channel id. Forward any message from the channel to @id_bot or @getidsbot. It replies with the id, a number that starts with -100. Paste that number below.
  5. The library belongs to one channel. Replace is refused once videos are already indexed, because the stream files point at messages in this channel.

Telegram search

This account searches Telegram for a requested film, for example #tm_m_603. A file that is found is copied into the library. The next search uses the new setting.

Shared library

New files posted to the channel are posted again with a caption that other installations can read: the title, its TMDB id, the subtitle tracks and a signature. Films you already have are left as they are. Turning it on needs a restart. Nothing has to be set up for other installations: a key is believed once its posts have been checked against their files, and ignored if they are wrong.

Home videos

Personal videos and photos. Their own Telegram channel, and a Jellyfin library called Home Videos and Photos. Nothing arrives from torrents, news, or other channels. You post in this channel, or you sync folders from this computer. Every bot must be an admin, with permission to post. Saving the channel needs a restart.

Away from home

At home, open an address tagged “At home”. Away from home, use Tailscale. It is a private network between your own devices. Nothing is published on the public internet.

Setup

  1. Install Tailscale on this computer.
  2. Install it on the phone or the TV.
  3. Sign both devices in to the same Tailscale account.
  4. Open the address tagged “Away from home” below.
  5. Do not turn on Tailscale Funnel. Funnel would publish Jellyfin to the whole internet, and it is a poor fit for video. No router port has to be opened.

Folders

Folders that hold your videos. The Telegram library and the downloads folder are never listed. Choosing folders works from this computer or over Tailscale.

Files

Uploads follow the same pace as downloads and go through the signed-in accounts, one file per account. A file larger than every account can send is refused, not split.

Torrents

One switch for the whole chain: Seerr asks Radarr and Sonarr for a film or an episode, qBittorrent fetches it, a Telegram account you sign in here posts it to the channel, and the file on disk is deleted after Jellyfin has probed it. It is off until you turn it on. To fill the library from other Telegram channels instead, use the Channels tab.

Off
Torrents connect this computer to strangers and can be illegal where you live. Your address is visible to other people in the swarm. Leave this off unless you accept that.

Telegram account

Sign in first. Torrents, Channels and the other tools below it open once an account is signed in, and each has its own switch. The account must be an admin of the library channel with permission to post.

Add a channel

How do I get a channel id?
  1. A public channel has a username. Give it as @name or https://t.me/name, and skip the rest.
  2. For a private channel, join it first with the account you signed in with. Telegram only lets an account read a private channel it is a member of.
  3. In Telegram, forward any message from that channel to @id_bot or @getidsbot.
  4. The bot replies with the channel id, a number that starts with -100. Copy it and paste it below.
  5. A link to a message also works, such as https://t.me/c/1234567890/5. An invite link (t.me/+…) does not.
